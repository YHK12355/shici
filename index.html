      MEMORY

      怎么记更牢

      1. 先想，再翻。看到单词先逼自己回忆三秒，再翻面。回忆这个动作本身，比反复看十遍更有用。
      2. 写一个只属于你的联想。谐音、画面、离谱的段子都行。自己编的钩子，比别人的记忆法更容易钩住。
      3. 换着练。认词 → 回想 → 拼写。认词是混脸熟，回想和拼写才是真正把它从脑子里拽出来。
      4. 少而勤。每天十个，连着来。比起周末一口气背一百个，大脑更吃“隔天再见”这一套。

      小建议：先用「认词」过一遍，第二天用「回想」，第三天用「拼写」。记不住没关系，选「忘了」让它再回来。
