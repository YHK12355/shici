# 拾词 · 每天拾几个词

一个可公开访问、也支持离线使用的背单词应用。词库覆盖：四级、六级、考研、雅思。默认每天 10 个词，按「认词 → 回想 → 拼写」的节奏来。

**在线使用：https://yhk12355.github.io/shici/**  
**源码仓库：https://github.com/YHK12355/shici**

建议用 Chrome / Edge 打开。手机浏览器也能用，但不能直接点电脑上的文件路径，需要走下面的「手机打开」。

## 排序与分篇

在「词库」里可以切换：

- **按篇**：按篇章顺序排列，每篇 100 词（雅思是主题篇）。
- **A→Z**：按首字母排序。
- **乱序**：随机排列，每次切换会重新洗牌。
- **篇章下拉框**：只看某一篇；选中后会出现「学习这一篇」，用当前顺序学这一篇的 10 个词。
- **显示更多**：默认每次渲染 100 条，避免手机上卡顿。

雅思的 22 个主题是：自然地理、植物研究、动物保护、太空探索、学校教育、科技发明、文化历史、语言演化、娱乐运动、物品材料、时尚潮流、饮食健康、建筑场所、交通旅行、国家政府、社会经济、法律法规、沙场争锋、社会角色、行为动作、身心健康、时间日期。

这是参考《雅思词汇真经》的**主题式分篇思路**，用公开词库独立归类得到的，不复制原书的词表、词序或例句；分类是启发式结果，个别词可能不够准确。

## 记忆辅助

- **先想，再翻。** 卡片正面会提醒你先回忆三秒；主动回忆比反复看更有效。
- **写自己的记忆钩子。** 在单词详情里写一个谐音、画面或离谱的段子。自己编的联想最容易钩住，之后每次翻面都会看到。
- **每日 10 个，少而勤。** 默认目标已经调小，也可以在设置里改成 5 / 10 / 20 / 30 / 50。
- **易错本。** 评价「忘了」的词会记一次 lapse，词库里点「易错」就能集中看，也可以一键「复习易错词」。
- **间隔复习。** 每个词独立记录熟练度，按「忘了 / 模糊 / 记得」安排下次出现的时间。

首页的「怎么记更牢？」里有完整说明。

## 网站上线

这个项目没有后端，整个网站由 `index.html` + `data.js` 两个静态文件组成：前者是界面，后者是 3.5MB 的词库数据。部署包是 `website.zip`，解压后把两个文件一起上传；只传 `index.html` 会缺少词库。

把这两个文件一起上传到任意静态托管，就能给所有人一个公开网址：

- **GitHub Pages**：新建仓库，上传 `index.html` 和 `data.js`，Settings → Pages → 从 `main` 分支根目录发布。
- **Cloudflare Pages**：Create a project → Upload assets，上传包含两个文件的文件夹或 `website.zip`。
- **Netlify Drop**：打开 `https://app.netlify.com/drop`，把包含两个文件的文件夹拖进去。
- **Vercel**：导入仓库，或拖入包含两个文件的文件夹。

公开部署后，每个访客的学习进度仍然只保存在**他们自己的浏览器**里，不会上传到服务器，也不会互相串。词库约 3.6 MB，静态托管都能放。

> 数据来源的署名写在应用「设置」底部和本 README 的「词库来源」里；公开部署时请保留。

## 手机打开

`index.html` 是 Mac 上的本地文件，手机直接访问 `file://...` 或 Finder 路径是打不开的。要让手机用，得让 Mac 临时当一台小服务器：

1. Mac 和手机连同一个 Wi-Fi。
2. 双击本目录里的 `start-server.command`，或者在终端运行 `./start-server.command`。
3. 终端会打印「手机打开」的地址，在手机浏览器里打开它，例如：
   `http://192.168.1.12:8787/`
4. 如果 IP 地址打不开，可以试试：
   `http://haokeyudeMacBook-Pro.local:8787/`
5. Mac 睡眠、断开 Wi-Fi 或关闭终端后，链接会失效。

打不开时依次检查：

- 手机是不是连着蜂窝网络或 VPN？切回和 Mac 同一个 Wi-Fi。
- 路由器是否开了「设备隔离 / AP 隔离」？开了的话设备之间互相访问不了。
- 终端里显示的 IP 是不是变了？以终端输出的地址为准。

手机上的进度是按网址保存在浏览器里的。尽量每次用同一个地址进入；IP 变了的话，优先用 `.local` 地址，或者在统计页导出 / 导入进度。

## 进度存在哪

进度保存在浏览器的 `localStorage` 里，键名是 `shici.v1`，包括复习记录、每日统计和你的记忆钩子。它不会上传到任何地方。

注意：

- 换浏览器、换设备不会同步。
- 清除浏览器网站数据会丢失进度，建议偶尔在统计页导出备份。
- 部分浏览器（尤其 Safari）会限制 `file://` 页面的本地存储；遇到提示时，换 Chrome / Edge 打开即可。
